# Licenças e fontes dos áudios

Os arquivos desta lista são distribuídos localmente em `public/audio/`. Nenhum som é
carregado de uma plataforma externa durante o jogo.

Para padronizar a experiência, os arquivos foram convertidos para MP3 mono, tiveram silêncio
inicial reduzido quando necessário, duração limitada e volume normalizado. As licenças
originais permanecem aplicáveis aos arquivos derivados.

## Instrumentos

Os arquivos `piano.mp3`, `guitar-acoustic.mp3`, `flute.mp3`, `trumpet.mp3` e `violin.mp3`
foram derivados das amostras C4 da coleção **Tone.js Instruments**, organizada por Nicholaus
P. Brosowsky e disponibilizada sob CC BY 3.0.

- Fonte: [Tone.js Instruments](https://github.com/nbrosowsky/tonejs-instruments)
- Licença das amostras: [Creative Commons BY 3.0](https://creativecommons.org/licenses/by/3.0/)
- Origens informadas pela coleção: VSO2 para piano, flauta, trompete e violino; University of
  Iowa Musical Instrument Samples para violão acústico.

O arquivo `drums.mp3` foi sintetizado para o projeto com tons e ruído processados, sem uso de
amostra externa.
